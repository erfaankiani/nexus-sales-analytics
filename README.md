# NEXUS Sales Analytics Dashboard

A modern sales analytics dashboard built with Python, Pandas, Streamlit, and Plotly.

## Features

- Upload CSV and Excel sales files
- Calculate total revenue and units sold
- Compare product performance
- Interactive revenue and quantity charts
- Filter sales by product
- Optional date filtering
- Download filtered sales reports
- Basic data validation and cleaning

## Required Columns

- `Product`
- `Price`
- `Quantity`

An optional `Date` column enables date filtering.

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python -m streamlit run app.py
```
